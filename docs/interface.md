# Interfaces

This file is the source of truth for every external interface of the scheduler.
`tools/arch_check.py` (Phase 2) checks that the constants in
`src/proto/wire.h` and `ue_sim/ue_sim/wire.py` match the table below.

## 1. UE report datagram (UDP)

One UDP datagram carries one message. All multi-byte fields are **big-endian**
(network byte order). Default port: **38472/udp**.

### Header (8 bytes)

| Offset | Size | Field         | Value / meaning                               |
|-------:|-----:|---------------|-----------------------------------------------|
| 0      | 2    | `magic`       | `0x4E52` (ASCII "NR")                          |
| 2      | 1    | `version`     | `1`                                           |
| 3      | 1    | `msg_type`    | `1` = UE_REPORT (no other types defined yet)  |
| 4      | 2    | `payload_len` | bytes after the header; must equal datagram size − 8 |
| 6      | 2    | `reserved`    | sender writes 0; receiver ignores             |

### UE_REPORT payload: N records of 8 bytes, N ≥ 1

| Offset | Size | Field       | Meaning                                              |
|-------:|-----:|-------------|------------------------------------------------------|
| 0      | 2    | `ue_id`     | UE identifier within the cell (like a C-RNTI)        |
| 2      | 1    | `cqi`       | latest wideband CQI, 1..15 (TS 38.214 CQI Table 1)   |
| 3      | 1    | `reserved`  | sender writes 0; receiver ignores                    |
| 4      | 4    | `new_bytes` | bytes that arrived in this UE's downlink buffer since its last report |

`new_bytes` is a delta, not a total: the scheduler owns the buffer state and
drains it as it schedules. Senders keep datagrams to ≤ 128 records (1032 bytes)
so they fit in one Ethernet frame.

### Example

UE 0x0102, CQI 9, 0x0A0B0C0D new bytes:

```
4E 52 01 01 00 08 00 00   01 02 09 00 0A 0B 0C 0D
```

(This exact vector is checked in both `tests/unit/test_wire.cpp` and
`ue_sim/tests/test_ue_sim.py`.)

### Validation: whole datagram rejected, nothing applied

Checks run in this order; the first failure is the counted reason.

| Reason (`nrs_malformed_packets_by_reason_total{reason=...}`) | Condition |
|---|---|
| `truncated_header` | datagram shorter than 8 bytes |
| `bad_magic`        | `magic != 0x4E52` |
| `bad_version`      | `version != 1` |
| `unknown_type`     | `msg_type != 1` |
| `length_mismatch`  | `payload_len != datagram_size − 8` (truncated or trailing bytes) |
| `bad_payload_size` | `payload_len == 0` or not a multiple of 8 |
| `bad_cqi`          | any record has `cqi` outside 1..15 |

All-or-nothing: if record 5 of 10 is bad, records 1-4 are not applied either.
That way a corrupted datagram can never half-update the cell state.

## 2. Offline trace file (CSV)

```
slot,ue_id,cqi,new_bytes
0,0,7,10000
0,1,12,10000
1,0,8,10000
```

* The header line is exactly `slot,ue_id,cqi,new_bytes`.
* `slot` must not decrease from one row to the next. A row stamped with slot *s* is
  applied before the scheduler runs in slot *s*.
* Rows have the same meaning as datagram records. Rows with an out-of-range CQI
  are counted in `rejected_reports`. Syntax errors abort with the line number.
* Generated by `python -m ue_sim trace` and replayed by `nr_mac_scheduler --mode offline`.

## 3. KPI JSON (offline mode output)

`nr_mac_scheduler --mode offline --trace T --slots N --out kpi.json` writes:

| Key | Meaning |
|---|---|
| `policy` | scheduler used |
| `slots`, `duration_s` | slots simulated, `slots × slot duration` |
| `cell_throughput_bps` | total scheduled bits / duration |
| `ue_throughput_bps` | object `{ue_id: bps}` for every UE seen, served or not |
| `jain_fairness` | Jain index over `ue_throughput_bps` |
| `prb_utilization` | PRBs used / (slots × PRBs per slot) |
| `sched_time_p50_us`, `sched_time_p99_us` | wall-clock time of `Cell::run_slot` (machine-dependent) |
| `slot_overruns`, `malformed_packets` | always 0 offline (no clock, no network) |
| `rejected_reports`, `buffer_overflow_bytes`, `invariant_violations` | cell safety counters |

## 4. HTTP endpoints (default port 8080)

| Path | 200 when | 503 when |
|---|---|---|
| `/healthz` | the slot loop completed a slot within the last 2 s | slot loop stalled or never started |
| `/readyz`  | sockets bound and the first metrics snapshot published | starting up or shutting down |
| `/metrics` | always | n/a |

### Metrics (Prometheus text format 0.0.4)

| Metric | Type | Meaning |
|---|---|---|
| `nrs_info{policy,num_prbs}` | gauge | always 1; carries config as labels |
| `nrs_slots_total` | counter | slots executed |
| `nrs_slot_overruns_total` | counter | slots that finished after their deadline |
| `nrs_prbs_allocated_total` | counter | PRBs allocated |
| `nrs_bytes_scheduled_total` | counter | downlink bytes scheduled |
| `nrs_cell_throughput_bps` | gauge | mean since start |
| `nrs_prb_utilization` | gauge | since start |
| `nrs_jain_fairness` | gauge | over per-UE throughput since start |
| `nrs_sched_time_p50_us`, `nrs_sched_time_p99_us` | gauge | last 4096 slots |
| `nrs_sched_time_us` | histogram | per-slot scheduling time (buckets 1-1000 µs) |
| `nrs_datagrams_received_total` | counter | all datagrams, valid or not |
| `nrs_reports_received_total` | counter | records parsed and queued |
| `nrs_queue_drops_total` | counter | records dropped because the receiver→slot queue was full |
| `nrs_malformed_packets_total` | counter | datagrams rejected by the parser |
| `nrs_malformed_packets_by_reason_total{reason}` | counter | as above, split by reason |
| `nrs_rejected_reports_total` | counter | reports the cell refused (bad CQI, UE table full) |
| `nrs_buffer_overflow_bytes_total` | counter | bytes dropped at a full UE buffer |
| `nrs_invariant_violations_total` | counter | scheduler allocations rejected by the cell's safety checks |
| `nrs_ues` | gauge | UEs known to the cell |
| `nrs_ue_cqi{ue}`, `nrs_ue_buffer_bytes{ue}`, `nrs_ue_avg_throughput_bps{ue}` | gauge | per-UE state |
| `nrs_ue_bytes_scheduled_total{ue}` | counter | per-UE bytes |

## 5. Configuration

Precedence: built-in defaults < YAML file (`--config`) < environment variables.
Unknown keys and out-of-range values stop startup with exit code 1.

| YAML key | Env var | Default | Range |
|---|---|---|---|
| `policy` | `NRS_POLICY` | `proportional_fair` | `round_robin`, `proportional_fair`, `max_throughput` (aliases `rr`, `pf`, `maxt`) |
| `cell.num_prbs` | `NRS_NUM_PRBS` | 52 | 1-275 |
| `cell.overhead` | `NRS_OVERHEAD` | 0.14 | [0, 1) |
| `cell.ewma_time_constant_slots` | `NRS_EWMA_TC_SLOTS` | 100 | ≥ 1 |
| `cell.slot_duration_us` | `NRS_SLOT_US` | 1000 | 62-1000000 |
| `cell.max_ues` | `NRS_MAX_UES` | 1024 | 1-65536 |
| `cell.max_buffer_bytes` | `NRS_MAX_BUFFER_BYTES` | 4000000 | ≥ 1 |
| `network.udp_bind` / `udp_port` | `NRS_UDP_BIND` / `NRS_UDP_PORT` | 0.0.0.0 / 38472 | |
| `network.http_bind` / `http_port` | `NRS_HTTP_BIND` / `NRS_HTTP_PORT` | 0.0.0.0 / 8080 | |
| `network.queue_capacity` | `NRS_QUEUE_CAPACITY` | 65536 | 1-16777216 |
